Privacy Policy - DocSwap

Terakhir diperbarui: 26 April 2026

DocSwap adalah aplikasi konversi PDF ke DOCX menggunakan layanan pemrosesan jarak jauh. Kebijakan ini menjelaskan data apa yang diproses, untuk tujuan apa data digunakan, kepada siapa data dikirim, bagaimana data diamankan, berapa lama data dapat dipertahankan, dan pilihan apa yang tersedia bagi pengguna.

Kebijakan ini berlaku untuk aplikasi DocSwap dan pengembang/penerbit yang tercantum pada listing Google Play untuk aplikasi ini.

DocSwap tidak mewajibkan pendaftaran akun dan tidak membuat profil akun pengguna di dalam aplikasi. Jika Anda memiliki pertanyaan privasi atau permintaan penghapusan data, hubungi docswappdf@gmail.com.

1. Data yang Diproses

  • File PDF yang Anda pilih untuk dikonversi
  • Nama file dan ukuran file
  • Data teknis permintaan, termasuk alamat IP atau informasi koneksi serupa, untuk kuota harian, rate limiting, dan pencegahan penyalahgunaan
  • Riwayat konversi lokal, seperti nama file hasil, nama file sumber, ukuran file, tanggal konversi, dan lokasi file lokal
  • Metadata operasional terbatas, seperti nama file, ukuran file, status permintaan, pengenal teknis deduplikasi, dan data koneksi yang dapat muncul dalam observability atau log teknis hosting

DocSwap tidak dengan sengaja mengumpulkan data profil seperti nama atau email, kecuali Anda sendiri menghubungi kami melalui email support.

2. Tujuan Penggunaan

  • Menjalankan konversi PDF ke DOCX
  • Menyimpan hasil konversi dan riwayat secara lokal di perangkat Anda
  • Menegakkan kuota harian penggunaan
  • Menerapkan rate limiting dan perlindungan terhadap penyalahgunaan
  • Membuka atau membagikan file hasil saat Anda memicu tindakan tersebut

3. Pihak Ketiga

Saat Anda menekan tombol convert, file PDF dikirim ke backend DocSwap dan diteruskan ke Cloudmersive untuk diproses menjadi DOCX.

Cloudmersive bertindak sebagai penyedia layanan pemrosesan dokumen. Lihat kebijakan privasi mereka di cloudmersive.com/privacy-policy.

DocSwap tidak membagikan data untuk tujuan iklan atau pemasaran dan tidak menjual data pribadi Anda. File hanya dibagikan ke aplikasi lain ketika Anda secara eksplisit memilih tindakan share atau open.

4. Penyimpanan Lokal

  • Pada Android, file hasil konversi disimpan di penyimpanan lokal aplikasi
  • Aplikasi juga dapat membuat salinan ekspor ke folder Documents/DocSwap
  • Riwayat konversi disimpan secara lokal agar Anda dapat membuka kembali hasil sebelumnya
  • Pada web, riwayat konversi disimpan secara lokal di browser atau perangkat
  • Pada web, hasil dapat tersedia sebagai file sesi lokal atau browser sampai sesi dibersihkan

5. Izin dan Akses Perangkat

Pada Android, aplikasi dapat meminta akses terkait file atau penyimpanan untuk memilih file PDF, menyimpan file hasil konversi, membuka file hasil, dan membagikan file hasil ke aplikasi lain atas tindakan Anda. Akses ini digunakan untuk fungsi utama aplikasi dan bukan untuk tujuan iklan atau profiling.

6. Keamanan, Retensi, Penghapusan, dan Data at Rest

  • Data in transit: file dan data permintaan dikirim melalui HTTPS/TLS antara aplikasi, backend DocSwap, dan layanan konversi pihak ketiga
  • Data at rest di perangkat: file hasil, riwayat lokal, dan salinan ekspor tetap berada di perangkat Anda sampai Anda menghapusnya, membersihkan data aplikasi, atau uninstall aplikasi
  • Penyimpanan sementara di backend: respons hasil konversi dapat disimpan sementara untuk deduplikasi atau duplicate request handling selama sekitar 60 detik; reservation kuota dapat dipertahankan sekitar 10 menit sebelum dipangkas otomatis
  • Kuota harian: data kuota berlaku untuk hari kuota aktif; record lama tidak dipakai kembali untuk perhitungan kuota hari berikutnya, meskipun retensi internal pada infrastruktur hosting dapat mengikuti kebijakan platform
  • Log teknis dan observability: penyedia hosting atau layanan terkait dapat menyimpan metadata teknis terbatas untuk kebutuhan operasional, reliabilitas, debugging, keamanan, dan pencegahan penyalahgunaan sesuai pengaturan platform dan kebijakan mereka
  • Arsip permanen dokumen: backend DocSwap dirancang agar tidak dengan sengaja menyimpan arsip jangka panjang file dokumen yang diunggah untuk konversi setelah proses konversi selesai
  • Penegasan enkripsi: kebijakan ini menegaskan penggunaan enkripsi untuk data in transit; DocSwap tidak membuat klaim terpisah bahwa seluruh data at rest selalu dienkripsi secara mandiri oleh aplikasi, karena perlindungan data at rest juga bergantung pada penyimpanan perangkat, sistem operasi, hosting, dan penyedia layanan terkait
  • Retensi pihak ketiga: retensi data pada penyedia pihak ketiga seperti Cloudmersive dan hosting mengikuti kebijakan privasi serta pengaturan platform mereka masing-masing

7. Iklan dan Analitik

Versi DocSwap saat ini tidak menyertakan SDK iklan pihak ketiga seperti AdMob maupun SDK analitik/pelacakan pihak ketiga seperti Firebase Analytics.

8. Pilihan Pengguna

  • Anda dapat menghapus riwayat lokal melalui aplikasi
  • Anda dapat menghapus file hasil konversi dari perangkat Anda
  • Anda dapat membersihkan data aplikasi atau uninstall aplikasi
  • Karena DocSwap tidak membuat akun pengguna di dalam aplikasi, tidak ada alur penghapusan akun di dalam aplikasi

9. Kontak

Untuk pertanyaan terkait privasi atau permintaan data, hubungi: docswappdf@gmail.com

10. Catatan Publikasi

Versi privacy policy yang dipublikasikan pada URL publik harus konsisten secara substansi dengan kebijakan di dalam aplikasi ini.
